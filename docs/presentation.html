Stops, never guesses

Stops at the first blocked ticket; its Log is the handoff. A rerun resumes. Never merges, marks ready, or deploys.

A read-only page that shows every ticket live: Waiting, Ready, Building, Done, Needs attention.

AGENTS.md in action · Illustrative08 / 12

Short repo rules shape real decisions.

Invariant

Protect the boundary

Report totals change only with approval.
List the affected reports before changing how a total is computed.

Command

Use the actual proof

Tests run offline; do not weaken assertions.
Use the repo’s test commands, not a guessed test strategy.

Pattern

Reuse the canonical example

Copy reports/summary.py for a new report.
Do not extend the legacy reports_v1/ code.

Repeated mistake

Same repo trap twice → one Invariant, Pattern, or automated check (/retro).

Independent review10 / 12

One fresh verifier.
Two axes, never merged.

Spec axis

Did it do what was asked?

Done-when items missing or partial.

Scope creep; implemented but wrong.

Quotes the spec line for each finding.

Standards axis

Does it follow the repo's rules?

Bugs, security, AGENTS.md invariants, ADRs.

Test integrity: nothing weakened, nothing tautological.

Cites the rule for each finding.

Proofs are reported Local and Live. A live check that cannot run here is NOT RUN, never a pass.

Verifier never edits files.Important findings block done.

You own
